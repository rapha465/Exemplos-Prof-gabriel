# Frontend

Esta pasta reúne a interface da aplicação de reservas da escola.

Arquivos principais:
- index.html
- recuperar-senha.html
- termos-e-privacidade.html
- styles.css
- script.js

Os dados da interface de salas ficam em `estrutura-de-dados/`:
- `Salas.html` e `Salas.css` - página e estilos da interface de reservas
- `salas.js` - dados de exemplo das salas e função para validar a capacidade
- `Reservas.js` - reservas iniciais e funções para detectar conflitos de horário
- `pagina-salas.js` - lógica da interface da página de salas
