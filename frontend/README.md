# Frontend

Esta pasta reúne a interface da aplicação de reservas da escola.

Arquivos principais:
- index.html
- recuperar-senha.html
- termos-e-privacidade.html
- styles.css
- script.js

Os dados da interface de salas ficam em `estrutura-de-dados/`:
- `Salas.html`, `Salas.css` e `Salas.js` - página, estilos e dados das salas, incluindo o formulário de reserva
- `Reservas.js` - reservas iniciais usadas pela demonstração e carregadas quando não há dados salvos no navegador
