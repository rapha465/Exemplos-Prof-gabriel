# Contexto 

Este é um sistema de reservas de uma escola.
Onde o foco são os professores e/ou outros funcionários solicitar reserva, e o gerente de salas aprovar a solicitação.

# Tecnologias

## Frontend
Para o Frontend é usado HTML, CSS e JavaScript moderno.

## Backend
Para o Backend é usado Node com JavaScript, porém em ambiente local usamos o MySQL em Docker.



# Arquitetura
O frontend e backend são criados em diretórios separados, e ligados por API.
A criação do backend utiliza o TDD (Test-Driven Development).

# Para criar as features

Utilize commit semântico.
Se as instruções da feature não estiverem claras, questione ao invés de supor.

# Guia de estilo

## Paleta de cores

- #F7F6EE
- #F4EADC
- #ECF0D4
- #EDCCCC
- #DCD5C2

Use a fonte https://fonts.google.com/share?selection.family=Creepster

Botões sempre devem ter bordas chanfradas.

Em formulários, campos obrigatórios devem ter bordas vermelhas com 3px e texto obrigatório acima dos campos.

Links devem mudar de cor quando o mouse está sobre.

# Acessibilidade

Siga os padrões de acessibilidade do WCAG 2.2.
